단계별 실습

0단계 — 부크크는 이렇게 움직입니다 (별님 설명 · 10분)

  • 부크크(bookk.co.kr)는 출판 비용 0원인 출판 서비스입니다.
  • 주문형(POD) 입니다. 주문이 들어올 때 한 권씩 찍어서 보내니 재고가 없습니다.
  • 내 책을 직접 받아 보고 싶을 때만 책값을 내고 주문하면 됩니다.
  • 흐름은 이렇습니다. 원고 PDF와 표지 PDF를 올린다 → 부크크가 검토한다 → 승인되면 판매가 시작된다.
  • 반려되면 사유를 읽고, 고쳐서 다시 올립니다. 반려는 흔한 일입니다.
  • 별님이 부크크 종이책 만들기 화면을 처음부터 끝까지 한 번(5분) 보여 드립니다. 판형 목록 · 표지 가이드 · 정가 칸이 어디 있는지 눈으로 봐 두세요. 보여 드리기만 하고 신청 단추는 누르지 않습니다.

실제로 반려되었던 사례 6가지 (5단계에서 점검표로 하나씩 확인합니다)

  1. 파일 이름 — 부크크는 파일 이름을 책 제목(도서명)으로 가져갑니다. 「최종.pdf」 같은 이름은 안 됩니다.
  2. 판권지 정가 — 판권지(책 앞쪽의 출판 정보 쪽)에 적은 정가와 등록한 정가가 다르면 반려됩니다.
  3. 판면 넘는 그림 — 그림·표가 여백 안쪽(판면)을 넘으면 반려됩니다.
  4. 특수 기호·이모지 — 동그라미 안 영문자 같은 특수 기호와 이모지는 인쇄에서 사라지거나 네모(⊠)로 나옵니다.
  5. 쪽수 — 등록하는 쪽수는 완성 PDF의 실제 장수로 셉니다.
  6. 앞부속 순서 — 빈 쪽 → 판권 → 제목 → 목차 순서입니다. 쪽번호는 바깥쪽에 둡니다.

1단계 — 부크크 가입 · 작가 등록 (5분)

① 무엇을, 왜
책을 올리려면 부크크 계정이 있어야 합니다. 책에 적힐 저자 이름도 이때 정합니다.
가입은 수업 전에 미리 해 두면 좋습니다. 미리 가입한 분은 2번을 건너뛰고 로그인만 합니다.

  1. 크롬에서 bookk.co.kr 을 엽니다.
  2. 회원가입을 누르고 화면 안내대로 가입합니다.
  3. 로그인한 뒤 작가(저자) 정보를 넣는 곳이 있으면, 책에 적힐 이름(본명 또는 필명)을 넣습니다.
  4. 저자 이름은 원고의 판권지·표지에 적힌 이름과 글자 하나까지 같게 씁니다.
  5. 정산 정보(계좌)를 넣으라는 칸이 나오면, 줌 화면 공유를 끄고 본인이 직접 넣습니다.

가입이 5분 안에 안 끝나면, 2단계 가) 문장을 클로드에게 먼저 보내 두고 클로드가 원고를 살피는 동안 가입을 마칩니다.
화면 이름은 조금 다를 수 있어요. 막히면 화면을 캡처해 클로드에게 보여 주세요.

② 💬 클로드에게 이렇게 말하세요 (막혔을 때)

지금 부크크(bookk.co.kr)에 가입하고 있어. 화면을 캡처해서 붙여넣을게.
이 화면에서 무엇을 눌러야 하는지 한 단계씩 쉬운 말로 알려 줘.
계좌번호나 주민등록번호 칸은 내가 직접 넣을 테니 그 값은 묻지 마.

캡처에 개인 정보가 보이면 가리고 붙여넣으세요.

③ ✅ 결과 확인
화면 위쪽에 내 이름이나 「로그아웃」 같은 단추가 보이면 로그인된 것입니다.

④ 막히면

  • 인증 문자가 안 온다 → 1~2분 기다렸다가 화면 안내대로 다시 받습니다. 단추를 여러 번 연달아 누르지 마세요.
  • 이미 가입된 이메일이라고 나온다 → 예전에 가입한 적이 있는 것입니다. 「비밀번호 찾기」로 본인이 직접 들어갑니다.

2단계 — 원고 규격 맞춰 PDF 다시 뽑기 (25분)

① 무엇을, 왜
3주차 PDF는 전자책으로 먼저 뽑은 것입니다. 종이책은 판형(책 크기)·여백·글자를 인쇄 규격에 맞춰야 합니다.
반려 사례 ③④⑤⑥ 이 바로 여기서 걸러집니다. 순서는 원고 점검 → 책 제목 정하기 → PDF 다시 뽑기 → PDF 점검 → 파일 이름 정리 입니다.

② 💬 클로드에게 이렇게 말하세요 (가·다·라는 복사용 문장, 나는 화면에서 할 일)

가) 원고에서 깨질 글자 찾기 · 책 제목 후보 보기

3주차에 e_book_maker 로 만든 내 책을 부크크 컬러 종이책으로 올리려고 해.
바탕 화면 3기_기록\03주차\기록.md 의 ④ 결과물 칸에서 원고 파일 위치를 찾아 줘.
그 원고에서 인쇄하면 사라지거나 네모로 깨질 수 있는 글자를 모두 찾아 줘.
(이모지, 동그라미 안 영문자 같은 특수 기호, 글꼴에 없을 수 있는 기호)
찾은 것은 「몇째 줄 · 그 글자 · 바꿀 글자」 표로 먼저 보여 줘.
내가 승인하면, 원본은 같은 폴더에 사본으로 남긴 뒤 고쳐 줘.
그리고 같은 기록.md 의 ⑤칸에 적어 둔 책 제목 후보 3개도 보여 줘.

책 제목은 후보 3개 중 하나로 지금 정합니다. 이 제목이 파일 이름·표지·도서 정보에 그대로 쓰이니, 오늘 정하면 바꾸지 않습니다. 후보를 적어 두지 않았다면 4주차 예고에서 준비해 오라고 한 책 제목을 씁니다.

나) e_book_maker 로 PDF 다시 뽑기 (화면에서 할 일)

  1. 3기_작업\e_book_maker 폴더의 실행 파일(run.bat)을 두 번 누릅니다. 3주차와 같습니다. 맥을 쓰시는 분은 3주차처럼 클로드에게 e_book_maker 실행을 맡깁니다.
  2. 고친 원고를 3주차처럼 넣습니다.
  3. 책 제목 칸에는 방금 정한 최종 제목을 적습니다. 지은이 칸에는 1단계에서 부크크에 넣은 저자 이름을 글자 하나까지 똑같이 적습니다. (칸 이름은 화면 안내를 따릅니다)
  4. 설정 화면에서 판형을 고릅니다. 0단계에서 별님이 보여 드린 부크크 판형 목록 가운데, e_book_maker 에도 있는 것을 고릅니다(예: A5). 고른 판형은 기억해 두세요. 3단계에서 기록.md 에 적고 부크크에서도 똑같이 고릅니다.
  5. 색 테마는 컬러 그대로 둡니다. 오늘 만드는 책은 컬러 책입니다.
  6. 여백은 줄이지 않습니다. 그림·표가 여백 밖으로 나가면 반려됩니다.
  7. PDF를 다시 만듭니다.

다) 다시 뽑은 PDF 보관 · 점검

방금 e_book_maker 로 다시 뽑은 PDF 가 어디에 저장됐는지 찾아 줘(3기_작업 안이나 '다운로드' 폴더에서 찾아도 돼. 다운로드 폴더는 이번에만).
가장 최근에 만들어진 그 PDF 를 바탕 화면 3기_작업\내책 폴더에 내책_부크크.pdf 라는 이름으로 복사해 줘.
원래 파일과 내책_A·B·C.pdf 는 건드리지 마.
PDF 를 읽는 데 필요한 꾸러미가 있으면 설치하기 전에 나에게 먼저 물어봐.
그다음 내책_부크크.pdf 를 점검해 줘.
1. 전체 쪽수(PDF 의 실제 장수)를 세어 줘.
2. 앞쪽이 「빈 쪽 → 판권 → 제목 → 목차」 순서인지 확인해 줘.
3. 쪽번호가 바깥쪽(홀수 쪽은 오른쪽, 짝수 쪽은 왼쪽)에 있는지 확인해 줘.
4. 그림이나 표가 여백 밖으로 나간 쪽이 있으면 쪽 번호를 알려 줘.
5. 네모(⊠)나 빈칸으로 깨진 글자가 있는지 찾아 줘.
6. 판권지에 정가가 적혀 있으면 그 금액을 알려 줘.
7. 한 쪽의 크기(가로×세로, mm)를 재서 알려 줘. 내가 고른 판형은 ○○(예: A5)야.

② 💬 클로드에게 이렇게 말하세요

부크크에 올리기 전 마지막 점검이야. 아래 8가지를 하나씩 확인해서 ✓/✗ 표로 보고해 줘.
파일은 바탕 화면 3기_작업\부크크_올릴파일 의 원고·표지 폴더에 있고, 숫자는 3기_기록\05주차\기록.md 에 있어.
1. 원고·표지 파일 이름이 책 제목과 같다
2. 판권지와 표지에 적힌 정가가 기록.md 의 「내가 정한 정가」와 같다 (적혀 있지 않으면 「정가 없음」)
3. 그림·표가 여백 밖으로 나간 쪽이 없다
4. 이모지·특수 기호·네모로 깨진 글자가 없다
5. 기록.md 의 쪽수가 원고 PDF 실제 장수와 같다
6. 앞쪽이 빈 쪽 → 판권 → 제목 → 목차 순서이고, 쪽번호가 바깥쪽이다
7. 원고 PDF 가 컬러로 되어 있다 (부크크에서 내지 컬러를 골랐는지는 내가 화면에서 확인)
8. 제목·저자 이름이 표지·판권지·제목 쪽에서 같다
✗ 가 있으면 고치는 방법을 먼저 알려 주고, 내 승인을 받은 뒤에 고쳐 줘.

③ ✅ 결과 확인
점검표 8칸이 모두 ✓ 입니다(②는 「정가 없음」이어도 됩니다).

④ 막히면

  • ② 가 ✗ 다 → 아래 문장을 클로드에게 보냅니다. 다시 뽑은 뒤에는 ① 파일 이름과 ⑤ 쪽수를 한 번 더 확인합니다. 표지에 찍힌 정가도 다르면 표지도 같은 값으로 고칩니다.
  • 최소 정가보다 낮게 넣을 수 없다 → 화면이 알려 주는 최소 금액 이상으로 정합니다.

② 가 ✗ 일 때 — 클로드에게

판권지 정가를 기록.md 의 「내가 정한 정가」로 맞추고 싶어.
바탕 화면 3기_작업\e_book_maker 의 설명서(README 같은 것)에서 판권지 정가를 어디서 바꾸는지 찾아 한 단계씩 알려 줘.
설명서에 없으면 「확인 필요」라고 말해 줘.
다시 뽑은 PDF 로 부크크_올릴파일\원고 의 파일을 바꾸기 전에 내 승인을 받아 줘.

6단계 — 올리기 · 도서 정보 · ISBN · 검토 요청 (20분)

① 무엇을, 왜
드디어 올립니다. 0단계에서 별님이 보여 드린 순서대로 각자 올립니다. 20분을 두었으니 서두르지 말고 한 칸씩 넣습니다. 화면 순서는 조금 다를 수 있어요. 화면 안내를 따릅니다.

  1. 원고 PDF를 올립니다. (부크크_올릴파일\원고)
  2. 표지 PDF를 올립니다. (부크크_올릴파일\표지)
  3. 도서 정보를 넣습니다. 제목·부제·저자·책 소개·분야·저자 소개는 부크크_등록문구.md 에서 복사합니다(화면에 그 칸이 있을 때).
  4. ISBN(책마다 붙는 국제 번호) 신청을 고릅니다. 번호가 언제 나오는지는 부크크 화면 안내를 따릅니다. 신청 전에 제목·저자를 한 번 더 확인하세요.
  5. 정가는 기록.md 의 「내가 정한 정가」를 그대로 넣습니다. 최소 정가가 이 화면에서 처음 보이면, 내 정가가 그 이상인지, 판권지에 정가가 있으면 그 금액과 같은지 다시 봅니다.
  6. 미리보기가 있으면 표지와 본문을 한 번 넘겨 봅니다.
  7. 마지막 신청 단추를 누릅니다. 별님이 책을 낼 때는 「승인 요청」이라는 이름이었습니다. 화면 이름은 조금 다를 수 있어요.
  8. 「검토 중」 같은 접수 표시가 보이면 캡처해서 3기_기록\캡처\05주차_부크크_검토접수.png 로 저장합니다.

같은 원고로 전자책도 따로 등록할 수 있습니다. 오늘은 종이책 하나에 집중하고, 원하는 분은 승인 뒤에 도전하세요.

② 💬 클로드에게 이렇게 말하세요 (등록 화면에서 막혔을 때)

부크크 종이책 등록 화면이야. 캡처를 붙여넣을게(개인 정보는 가렸어).
이 칸에 무엇을 넣어야 하는지 쉬운 말로 알려 줘.
넣을 글이 필요하면 바탕 화면 3기_기록\05주차\부크크_등록문구.md 에서 골라 줘.
모르는 선택 칸이면 짐작하지 말고 「부크크 안내에서 확인할 것」이라고 말해 줘.

③ ✅ 결과 확인
부크크의 내 책 목록(화면 이름은 다를 수 있어요)에 내 책이 「검토 중」 같은 상태로 보입니다. 이것이 오늘의 결과물입니다.

④ 막히면

  • 파일 올리기가 거절된다 → 화면에 나온 문구를 그대로 복사해 클로드에게 붙여넣고 「무엇을 고쳐야 하는지 알려 줘」라고 말합니다.
  • 모르는 선택 칸이 있다 → 캡처를 클로드에게 보여 줍니다. 그래도 모르면 단톡방에 캡처(개인 정보 가리고)를 올려 주세요.

🆘 자주 막히는 곳

1. 3주차 PDF가 어디 있는지 모르겠어요

바탕 화면 3기_작업과 3기_기록 폴더 안에서만 PDF 파일을 찾아서, 만든 날짜 순으로 보여 줘. 다른 폴더는 보지 마.

2. 쪽수가 자꾸 달라져요

쪽수는 언제나 마지막에 뽑은 PDF 기준입니다. 원고를 고치면 쪽수를 다시 세고, 책등을 다시 받아 적고, 표지를 맞춥니다.
원고 확정 → 쪽수 → 표지 순서를 지키면 표지를 두 번 만들 일이 없습니다.

3. 미리보기에서 글자가 네모(⊠)로 나와요

특수 기호나 이모지 때문입니다. 2단계 「가) 원고에서 깨질 글자 찾기」를 다시 하고 PDF를 다시 뽑습니다.

4. 정가를 바꿨어요

판권지(와 표지)에 정가가 적혀 있다면 같이 고칩니다. 5단계 ④ 의 문장으로 PDF를 다시 뽑아 다시 올리고, 점검표 ②를 다시 확인합니다.

5. 반려 알림이 왔어요

반려는 흔한 일입니다. 사유를 그대로 복사해 클로드에게 붙여넣으세요.

부크크에서 반려 알림이 왔어. 사유를 그대로 붙여넣을게.
(여기에 반려 사유 붙여넣기)
원고와 표지는 바탕 화면 3기_작업\부크크_올릴파일 에 있어.
1. 이 사유가 원고·표지의 어디를 말하는지 찾아서 알려 줘.
2. 고치는 방법을 먼저 보여 주고, 내 승인을 받은 뒤에 고쳐 줘.
3. 고친 뒤 올리기 전 점검표 8가지를 다시 확인해 줘.

6. 표지 크기가 맞지 않는다고 나와요

단위가 mm 인지 봅니다. 3단계 숫자를 다시 확인하고(종이나 쪽수를 바꿨다면 책등이 바뀝니다), 4단계 「다) 표지 점검」을 다시 합니다.
