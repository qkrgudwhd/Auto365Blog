1단계 · 왜 점수와 글 품질을 보나 (10분)

왜 하는지 — 지난 4주 동안 365blog 와 쇼츠 프로그램으로 글과 영상이 자동으로 올라갔습니다. 자동 발행은 시간을 아껴 주지만, 같은 틀로 찍어 낸 듯한 글이 쌓이면 블로그가 오히려 약해질 수 있습니다. 오늘은 숫자로 내 블로그를 재 보고, 사람만 넣을 수 있는 것을 더해 읽는 사람에게 도움이 되는 블로그로 바꾸는 길을 찾습니다.

먼저 알아 둘 세 가지

  1. 점수는 검색 회사의 진짜 순위 점수가 아닙니다. 블로그 SNS 닥터가 공개 화면에서 잰 값을 다섯 영역으로 묶어 100점으로 바꾼 「건강검진표」입니다. 어디가 약한지 찾는 도구로 씁니다.
  2. 「저품질」이라고 단정하지 않습니다. 네이버는 저품질 기준을 공개하지 않습니다. 그래서 프로그램도 「의심 신호」라고만 말합니다. 같은 문장 되풀이, 같은 제목 반복, 외부 링크가 너무 많은 글 같은 것들입니다.
  3. 애드센스도 결국 「글의 가치」를 봅니다. 애드센스가 승인하지 않는 흔한 까닭 가운데 하나가 「가치가 별로 없는 콘텐츠」입니다. 자동으로 만든 페이지, 직접 만든 내용이 거의 없는 페이지가 여기에 걸립니다.
흔한 생각실제로는
글을 많이 올리면 점수가 오른다활동성은 오르지만, 글이 얕고 비슷하면 콘텐츠 품질과 SEO·검색 점수가 깎입니다.
점수가 낮으면 블로그가 망한 것이다아닙니다. 점수는 「무엇부터 고칠지」 알려 주는 순서표입니다. 위에서부터 하나씩 고치면 됩니다.
못 잰 항목이 많으면 손해다못 잰 항목은 감점이 아니라 점수에서 뺍니다. 인스타그램처럼 공개 정보가 적은 곳이 억울하게 낮게 나오지 않게 한 것입니다.
애드센스는 글 수만 채우면 된다구글은 글 수를 숫자로 정해 두지 않았습니다. 충실하고 독창적인 글이 쌓여 있어야 심사자가 볼 것이 있습니다.

✅ 이렇게 보이면 성공 — 채팅창에 「많이보다 잘」 한 줄을 내 말로 남깁니다. 예) 「자동 글에 내 사진과 경험을 한 문단씩 더하겠다」.

6단계 · 애드센스 신청 준비 (15분)

왜 하는지 — 애드센스는 신청만 한다고 되는 것이 아니라, 구글이 내 사이트 전체를 검토합니다. 무엇이 모자란지 먼저 채우고 신청하면 헛걸음이 줄어듭니다. 블로그 SNS 닥터의 「② 애드센스 준비」 탭은 조건마다 지금 상태와 출처를 보여 줍니다. 오늘은 신청 직전까지 준비합니다. 실제 가입·신청은 본인이 수업 뒤에 합니다.

⚠ 먼저 — 내 블로그는 애드센스를 붙일 수 있는 곳인가요?

구글 블로거됨블로거 대시보드 → 수입
직접 설치한 워드프레스됨사이트 머리에 애드센스 코드 + ads.txt (Site Kit 플러그인으로도)

「② 애드센스 준비」 조건표 읽는 법

「🏥 처방에서 수술로」 탭 → 「② 애드센스 준비」를 엽니다. 표의 칸은 조건 · 지금 · 기준 · 판정 · 출처입니다. 줄을 누르면 아래에 고치는 법이 나옵니다. 출처 칸을 꼭 봅니다.

출처 표시뜻
구글 공식애드센스 고객센터 「자격 요건」에 적힌 것 — 자체 콘텐츠와 정책 준수, 나이 조건, 사이트 HTML 소스에 접근할 수 있을 것
구글 안내애드센스 고객센터의 계정 설정 안내에 적힌 것 — 사이트가 열리고 글이 보일 것, 개인정보처리방침, 결제 정보, 본인 인증, ads.txt
권장구글이 숫자로 정하지 않은 것입니다. 글 수, 글 깊이, 최근 활동, 운영자 소개, HTTPS, 주제 집중처럼 흔히 권하는 기준이며 승인을 보장하지 않습니다.
못 잼공개 화면으로 알 수 없는 것 — 서치콘솔 등록처럼 사람이 확인합니다

조건과 기준은 구글이 바꿀 수 있습니다. 신청하기 전에 애드센스 고객센터의 최신 공식 안내를 한 번 더 확인합니다.

필수 페이지 초안 만들기

왜 하는지 — 구글 안내는 광고를 보이기 전에 개인정보 보호 규정을 지키라고 하며, 기다리는 동안 개인정보처리방침을 준비하라고 합니다. 운영자 소개는 「누가 쓰는 블로그인지」를 밝혀 신뢰를 줍니다.

  1. 「② 애드센스 준비」 아래쪽의 「📄 필수 페이지 초안 만들기」를 누릅니다.
  2. 「운영자 이름(별명)」을 묻습니다. 블로그에 공개해도 되는 이름이나 별명을 적습니다.
  3. 「문의 받을 메일 주소」를 묻습니다. 공개해도 되는 문의용 메일만 적습니다. 모르겠으면 비워 둡니다(〔 〕로 남습니다).
  4. 「블로그가 다루는 주제」를 한 줄로 적습니다.
  5. 폴더가 열리고 개인정보처리방침.html 과 운영자 소개.html 두 파일이 보입니다. 두 번 눌러 열어 읽습니다.
  6. 〔 〕 칸(전공·경력, 다루는 주제와 글 쓰는 기준 등)을 메모해 둡니다. 채우는 것은 과제입니다.

🔒 초안은 법률 자문이 아닙니다. 읽고 내 블로그에 맞게 고친 뒤 올립니다. 운영자 소개에는 사실만 씁니다.

올리는 곳 — 티스토리는 블로그 관리 → 콘텐츠 → 「페이지 관리」에서 새 페이지로 하나씩 올리고, 꾸미기 → 메뉴에서 두 페이지를 메뉴에 겁니다. 블로거와 워드프레스는 「페이지」에 올리고 메뉴에 겁니다. 메뉴에 걸어야 첫 화면에서 보이고, 다시 진단할 때 프로그램이 「보임」으로 알아봅니다.

신청 순서 — 누가 무엇을 하나

「⓪ 탈바꿈 순서」 탭에도 같은 단계가 「누가 · 지금」과 함께 나옵니다. 사람이 할 단계는 「🖼 그림 안내 보기」로 한 걸음씩 볼 수 있고, 끝낸 단계는 「✅ 했어요」로 표시해 둡니다.

단계할 일누가
1. 조건 채우기조건표에서 「아님」인 줄부터 — 글은 「① 글 수술」, 페이지는 「필수 페이지 초안」나 + 프로그램
2. 애드센스 가입본인 구글 계정으로 가입, 내 블로그 주소 입력, 약관을 읽고 동의본인
3. 결제 정보은행 정보와 똑같은 이름 · 우편번호까지 전체 주소 · 맞는 전화번호본인
4. 사이트 연결티스토리 「연동하기」 / 블로거 「수입」 / 워드프레스 코드·ads.txt본인 (구글 계정 고르기·허용)

검토 기간, 본인 인증 기한, 계정 설정을 마쳐야 하는 기한도 구글 안내에 정해져 있습니다. 프로그램의 그림 안내와 「▶ 애드센스 신청 가이드」 영상(연동 · ads.txt · 개인정보처리방침 · 동의 메시지)에서 확인하고, 신청 당일 고객센터의 최신 안내와 다시 맞춰 봅니다. 결과가 언제 오는지, 승인될지는 누구도 미리 약속할 수 없습니다.

ads.txt 는? — 조건표에 「ads.txt」 줄이 있으면 그 판정을 봅니다. 티스토리 하위 주소(이름.tistory.com)는 「해당 없음」으로 나옵니다. 블로거는 설정 → 수익 창출에서 「맞춤 ads.txt」를 켜고 상자에 내 번호 줄을 넣고 저장해야 합니다. 스위치만 켜고 상자가 비면 빈 ads.txt 가 나갑니다.

콘텐츠 정책 위반저작권 있는 사진·글, 금지된 주제, 고지 없는 제휴 링크를 지웁니다.

🆘 자주 막히는 곳

  1. 점수가 지난번보다 크게 내려갔다 → 잴 수 있는 항목이 늘면 약한 곳이 드러나 점수가 정직해집니다(열쇠를 넣었거나 정밀 진단을 했을 때). 감점표에서 새로 생긴 줄을 봅니다.
  2. 인스타그램·틱톡이 「잴 수 없음」 → 로그인 없이는 공개 정보가 거의 없는 플랫폼입니다. 감점이 아닙니다.
  3. 열쇠를 넣었는데 「받지 않음」 → 열쇠를 다시 복사해 넣습니다. 앞뒤에 빈칸이 섞이지 않았는지, 네이버는 사용 API 에 「검색」을 골랐는지 봅니다.
  4. 다른 컴퓨터로 옮겼더니 열쇠가 사라졌다 → 정상입니다. 열쇠는 그 컴퓨터에서만 풀립니다. 다시 넣습니다. 진단 이력은 data 폴더를 함께 옮기면 따라옵니다.
  5. 클로드가 애드센스 기준 숫자를 단정한다 → 「그 숫자의 출처가 애드센스 고객센터인지, 권장인지 구분해 줘. 모르면 '확인 필요'로 적어 줘.」
  6. 화면 공유 중에 열쇠·메일이 보일 뻔했다 → 바로 공유를 멈추고, 열쇠가 보였다면 그 자리에서 지우고 새로 만듭니다.

📎 더 배우기 (집에서)

수업 뒤 혼자 따라 하기입니다. 과제가 아닙니다. 꼭 할 것은 아래 「✅ 수료 과제」 세 가지뿐입니다. 막히면 단톡방에 캡처와 함께 물어보세요(열쇠·개인 정보는 가리고).

① 네이버 검색 API 열쇠 넣기 — 검색 누락 검사 (무료)

왜 하는지 — 「내 글이 네이버 검색에 나오는가」를 잽니다. 검색 화면을 기계로 긁지 않고 공식 API 로 묻기 때문에 차단 걱정이 없습니다.

  1. developers.naver.com 에 내 네이버 아이디로 로그인합니다(비밀번호는 본인이).
  2. 「Application」 → 「애플리케이션 등록」을 누릅니다.
  3. 이름은 아무거나(예: 블로그닥터), 사용 API 는 「검색」, 환경은 「WEB 설정」에 http://localhost 를 넣습니다.
  4. 「등록하기」를 누르면 Client ID 와 Client Secret 이 나옵니다.
  5. 프로그램 「설정」의 같은 이름 칸에 붙여넣고 「저장」 → 「연결 시험 (무료)」을 누릅니다.

✅ 이렇게 보이면 성공 — 연결 시험에서 「연결됨」이 나오고, 다시 진단하면 감점표에 「검색 누락」 줄이 생깁니다.

② 정밀 진단 — 본인 계정으로 설정까지

왜 하는지 — 공개 화면으로는 못 보는 관리 화면의 설정과 통계까지 읽어 「⚙ 설정 점검」 탭에 보탭니다.

  1. 크롬이 깔려 있는지 확인합니다.
  2. 「🔬 정밀 진단 (본인 로그인)」을 누르고 「예」를 누릅니다.
  3. 프로그램 전용 크롬 창이 열리면, 처음 한 번만 그 창에서 내가 직접 로그인합니다. 프로그램은 비밀번호를 치지 않습니다.
  4. 끝나면 「⚙ 설정 점검」 탭에서 「자동」이 붙은 줄을 고르고 「고른 줄 자동 수정」을 누릅니다. 무엇을 바꾸는지 먼저 묻습니다. 읽고 나서 허락합니다.

🔒 정밀 진단은 본인 계정으로만 합니다. 남의 계정으로 로그인해 읽는 것은 약관 위반이고 계정 정지 위험이 있습니다.

③ 한 달 정밀 진단과 일주일 뒤 재진단

  • 일주일 뒤 — 처방전의 재진단 권장일에 같은 주소로 다시 「🩺 진단 시작」. 「🗂 이력 (전·후)」 탭에서 점수가 어떻게 변했는지 선으로 봅니다.
  • 한 달에 한 번 — 「📅 한 달 정밀 진단」 탭은 기간 안의 글을 모두 재서 분야별 점검표 · 월간 통계 · 4주 처방 · 글별 처방을 냅니다. 「4주 처방」을 한 달 계획표로 씁니다.

④ 애드센스 실제로 신청하기

  1. 과제 2의 필수 페이지를 블로그에 올리고 메뉴에 겁니다.
  2. 다시 진단해 「② 애드센스 준비」 조건표에서 「아님」 줄이 줄었는지 봅니다.
  3. 오른쪽 안내란의 「▶ 애드센스 신청 가이드」 영상을 처음부터 끝까지 봅니다.
  4. 「⓪ 탈바꿈 순서」에서 사람 단계마다 「🖼 그림 안내 보기」를 열어 한 걸음씩 따라 합니다. 가입 · 약관 동의 · 결제 정보 · 본인 인증 · 계좌는 모두 본인이 직접 합니다.
  5. 신청 당일, 애드센스 고객센터의 최신 안내와 조건을 한 번 더 확인합니다.
  6. 끝낸 단계는 「✅ 했어요」로 표시하고, 기다리는 동안에도 글을 꾸준히 올립니다.
