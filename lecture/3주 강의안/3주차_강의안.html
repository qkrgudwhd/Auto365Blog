여는 말 · 부크크는 이렇게 움직입니다 (별님 설명)

왜 하는지 — 오늘 할 일 전체를 먼저 한 번 보고 시작하면, 각자 할 때 「지금 어디쯤인지」 길을 잃지 않습니다.

  • 부크크(bookk.co.kr)는 출판 비용 0원인 주문형(POD) 출판 서비스입니다. 주문이 들어올 때 한 권씩 찍어 보내니 재고가 없습니다. 내 책을 직접 받아 보고 싶을 때만 책값을 내고 주문합니다.
  • 흐름: 원고 PDF 와 표지 PDF 를 올린다 → 부크크가 검토한다 → 승인되면 판매가 시작된다. 반려되면 사유를 읽고 고쳐서 다시 올립니다. 반려는 흔한 일입니다.
  • 별님이 종이책 만들기 화면을 처음부터 끝까지 한 번 보여 드립니다. 판형 목록 · 표지 가이드 · 정가 칸이 어디 있는지 눈으로 봐 두세요. 신청 단추는 누르지 않습니다.

실제로 반려되었던 사례 6가지 (6단계 점검표에서 하나씩 확인합니다)

  1. 파일 이름 — 부크크는 파일 이름을 책 제목(도서명)으로 가져갑니다. 「최종.pdf」 같은 이름은 안 됩니다.
  2. 판권지 정가 — 판권지에 적은 정가와 등록한 정가가 다르면 반려됩니다.
  3. 판면 넘는 그림 — 그림·표가 여백 안쪽(판면)을 넘으면 반려됩니다.
  4. 특수 기호·이모지 — 인쇄에서 사라지거나 네모(⊠)로 나옵니다.
  5. 쪽수 — 등록하는 쪽수는 완성 PDF 의 실제 장수로 셉니다.
  6. 앞부속 순서 — 빈 쪽 → 판권 → 제목 → 목차 순서입니다. 쪽번호는 바깥쪽에 둡니다.

1단계 · e_book_maker 꺼내고 켜기

왜 하는지 — 이걸 해 두면 오늘 내내 이 화면 하나로 책을 만듭니다. 처음 한 번은 꾸러미(프로그램 부품)를 인터넷에서 받느라 몇 분 걸리니, 수업 앞쪽에 켜 두고 기다리는 동안 2단계를 합니다.

손으로 할 일 — 압축 풀기

  1. Windows 키와 E 를 함께 누릅니다. 파일 탐색기가 열립니다.
  2. 「문서」 → 「카카오톡 받은 파일」 폴더를 엽니다. 다른 곳에 받았다면 그곳을 엽니다.
  3. 이름에 e_book_maker 가 들어간 압축 파일을 한 번 눌러 고르고 Ctrl+C 를 누릅니다.
  4. 「바탕 화면」 → 3기_작업 폴더를 열고, 빈 곳을 한 번 누른 뒤 Ctrl+V 를 누릅니다.
  5. 붙여넣은 압축 파일 위에서 마우스 오른쪽 단추 → 「모두 압축 풀기」 → 「압축 풀기」를 누릅니다. 압축 파일은 지우지 않습니다.

손으로 할 일 — 켜기

  1. 풀린 폴더에서 run.bat(확장자가 숨겨져 있으면 run, 종류는 「Windows 배치 파일」)을 찾아 두 번 누릅니다. 못 찾겠으면 아래 💬 문장을 씁니다.
  2. 파란 경고 창이 뜨면 아래 🧯 첫 줄대로 합니다.
  3. 검은 창에 글자가 올라가기 시작하면 맨 위 오른쪽의 「─」(최소화)를 눌러 내립니다. 「X」(닫기)는 누르지 않습니다.
  4. 기다리지 말고 2단계로 넘어갑니다. 브라우저에 새 탭이 저절로 열리면 그때 눌러 봅니다.

부크크의 내 책 목록에 내 책 제목이 한 줄 보이고, 그 옆 상태가 「검토 중」 같은 말로 나옵니다. 이것이 오늘의 결과물입니다.

🧯 막히면

  • ② 가 ✗ 다 → 판권지 정가를 「내가 정한 정가」로 맞춰 3단계부터 PDF 를 다시 뽑고, ① 파일 이름과 ⑤ 쪽수를 한 번 더 확인합니다. 표지에 찍힌 정가도 다르면 표지도 고칩니다.
  • 파일 올리기가 거절된다 → 화면에 나온 문구를 그대로 복사해 클로드에게 붙여넣고 「무엇을 고쳐야 하는지 알려 줘」라고 말합니다.
  • 올리기가 한참 멈춰 있다 → 파일이 클수록 오래 걸립니다. 단추를 다시 누르지 말고 기다립니다.
  • 시간 안에 못 끝냈다 → 어디까지 했는지 기록.md 에 적고, 과제 1로 이어 합니다.

끄는 법, 다시 켜는 법

브라우저의 e_book_maker 탭을 닫고, 검은 창의 「X」를 눌러 닫습니다. 다음에 쓸 때는 run.bat 을 다시 두 번 누릅니다. 두 번째부터는 금방 뜹니다.

🆘 자주 막히는 곳

  1. 첫 실행이 너무 오래 걸린다 — 꾸러미를 받는 중이면 정상입니다. 몇 분이 지나도 검은 창이 한 줄도 바뀌지 않으면 캡처해 클로드에게 보여 주세요.
  2. 「python 을 찾을 수 없다」 같은 문구 — 클로드에게 「1주차에 설치한 파이썬이 잘 잡혀 있는지 확인하고, 고치기 전에 나에게 먼저 설명해 줘」라고 말합니다.
  3. 실수로 탭을 닫았다 — 검은 창이 살아 있으면 그 창의 http://localhost:… 주소를 브라우저에 붙여넣습니다. 검은 창까지 닫았다면 run.bat 을 다시 두 번 누릅니다.
  4. PDF 나 미리보기에 네모(⊠)가 있다 — 이모지나 특수 기호 탓입니다. 2단계의 깨질 글자 찾기를 다시 하고 PDF 를 다시 뽑습니다.
  5. 쪽수가 자꾸 달라진다 — 쪽수는 언제나 마지막에 뽑은 PDF 기준입니다. 원고 확정 → 쪽수 → 표지 순서를 지키면 표지를 두 번 만들 일이 없습니다.
  6. 판권지의 ISBN 칸은 어떻게 하나요? — ISBN 번호는 부크크가 발급합니다. 별님이 책을 낼 때는 부크크가 실제 번호를 표지 뒤 바코드와 판매 화면에 넣었습니다. 판권지 칸을 어떻게 둘지는 부크크 안내를 따르고, 모르겠으면 안내를 캡처해 클로드에게 찾아 달라고 합니다(안내에 없으면 '확인 필요').
  7. 검토 중인데 원고를 고치고 싶다 — 바꾸는 방법은 부크크 화면 안내를 따릅니다. 고친다면 3단계부터 다시 뽑고 점검표 8가지를 거쳐 올립니다.
  8. 반려 알림이 왔다 — 반려는 흔한 일입니다. 사유를 그대로 클로드에게 붙여넣으세요.
부크크에서 반려 알림이 왔어. 사유를 그대로 붙여넣을게.
(여기에 반려 사유 붙여넣기)
원고와 표지는 바탕 화면 3기_작업\부크크_올릴파일 에 있어.
1. 이 사유가 원고·표지의 어디를 말하는지 찾아서 알려 줘.
2. 고치는 방법을 먼저 보여 주고, 내 승인을 받은 뒤에 고쳐 줘.
3. 고친 뒤 올리기 전 점검표 8가지를 다시 확인해 줘.

📎 더 배우기 (집에서)

먼저 읽어 주세요

수업 시간에는 하지 않습니다. 과제가 아닙니다. 과제를 마친 뒤 하고 싶은 분만 혼자 따라 하세요. 순서대로 하지 않아도 됩니다. 막히면 단톡방에 번호(예: 「더 배우기 ②」)와 캡처를 올려 주세요. 검토 중인 책의 파일(부크크_올릴파일)은 건드리지 않습니다.

① 설정을 바꿔 두 번 뽑고 견주기 — 목차는 저절로 따라온다

왜 하는지 — 「설정을 바꿔도 목차 쪽번호는 저절로 따라온다」를 눈으로 봐 두면, 다음 책에서 판형·여백을 바꿀 때 겁나지 않습니다.

✅ 성공 — 쪽수나 목차 쪽번호가 달라졌고, 손으로 고친 곳은 하나도 없습니다. 🧯 막히면 — 쪽수가 그대로라면 원고가 짧아 장마다 한 쪽 안에 다 들어가서입니다. 글자 크기는 가장 크게, 판형은 가장 작게 골라 다시 뽑아 보세요. 장을 하나 더 쓰고 다시 뽑으면, 손대지 않아도 목차에 새 장이 생기는 것도 볼 수 있습니다.

② 같은 원고로 전자책도 등록하기

종이책(주문형)은 주문이 들어오면 한 권씩 인쇄해 보내고, 전자책은 인쇄·배송 없이 파일로 읽습니다. 같은 원고로 따로 등록합니다. 종이책 승인 알림을 먼저 기다린 뒤에 하면 덜 헷갈립니다.

  1. 부크크에서 전자책 만들기(비슷한 이름)를 누릅니다.
  2. 안내 화면을 캡처해 아래 문장과 함께 클로드에게 보냅니다.
  3. 클로드가 정리해 준 순서대로 올리고, 6단계 점검표를 한 번 더 거칩니다.
부크크 전자책 등록 화면이야. 캡처를 붙여넣을게.
종이책 때 쓴 바탕 화면 3기_작업\부크크_올릴파일 의 원고·표지를 그대로 써도 되는지, 다른 규격이 필요한지 이 안내에서 찾아 줘.
안내에 없는 것은 짐작하지 말고 「확인 필요」라고 말해 줘.
전자책용 파일이 따로 필요하면 3기_작업\부크크_올릴파일_전자책 폴더를 만들어 거기에 만들고, 종이책 파일은 건드리지 마.

✅ 성공 — 내 책 목록에 같은 제목이 종이책·전자책 두 줄로 보입니다. 같은 내용을 여러 권으로 낸다면, 책 소개 맨 앞에 「이 내용은 ○○에도 들어 있습니다」라고 밝혀 두세요. 독자가 같은 내용을 두 번 사지 않게 됩니다.
