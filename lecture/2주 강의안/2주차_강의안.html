순서 — 하루에 한 걸음씩 해도 됩니다

  2. 주소 넣기 — 365blog 「⚙️ 설정 → 🔐 자격증명 → 📔 Tistory 블로그」 칸에 주소 앞부분 이름(○○○.tistory.com 이면 ○○○)을 넣고 「💾 저장 (3중 동기화)」.

  4. 셀렉터 4개 뽑기 — 평소 크롬에서 티스토리 글쓰기 화면(주소가 보통 /manage/newpost 로 끝남)을 열고 F12 로 뽑습니다.
    • # 제목 칸 · # 본문 칸 — 2단계와 같은 방법
    • # 완료 단추 — 화살표를 켠 상태에서만 누릅니다(평소처럼 누르면 작은 창이 열립니다. 그래도 글은 아직 안 올라갑니다)
    • # 공개 발행 단추 — 「완료」를 평소처럼 눌러 작은 창을 연 뒤, 화살표를 켜고 「공개 발행」을 누릅니다. 뽑고 나면 작은 창의 「취소」나 X 로 닫습니다. 화살표 없이 「공개 발행」을 누르면 글이 올라갑니다.
  5. 클로드에게 비교 맡기기 — 아래 문장을 보냅니다.
  6. 한 번만 발행 — 5단계와 똑같이 📔 티스토리 탭 → ✏️ 글쓰기 → 글쓰기 창 표시 체크 → 제목(수동) → [▶ 시작] 한 번.

③ 말로 순서 + 단추 메모로 새 일 맡기기

💡 왜 하나요 — 프로그램에 없는 작은 일도 클로드에게 맡길 수 있습니다. 비결은 두 가지 — 사람이 손으로 할 때의 순서를 말로 적고, 누를 곳마다 단추 메모를 붙이는 것입니다.

단추 메모 쓰는 법 — 한 줄에 # 이름, 그 아래에 F12 → Copy element(또는 Copy selector)로 복사한 조각. 기록.md 「오늘 뽑은 셀렉터」 칸과 같은 모양입니다.

  1. 하고 싶은 일을 한 문장으로 적습니다.
  2. 사람이 손으로 할 때의 순서를 번호로 적습니다(어느 주소를 열고 → 무엇을 보고 → 무엇을 누르는지).
  3. 순서에 나오는 단추·칸마다 F12 로 단추 메모를 만듭니다.
  4. 지킬 것을 적습니다 — 로그인은 내가, 누르면 안 되는 단추, 한 번만, 먼저 계획 보고.
  5. 클로드에게 보내고, 계획을 읽은 뒤 「좋아」 → 한 번 실행 → 결과 확인.
