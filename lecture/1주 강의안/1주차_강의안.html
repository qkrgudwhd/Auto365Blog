1단계 · 클로드 설치 — 직접 하는 유일한 설치 (20:10~20:25)

왜 하나요

클로드 데스크톱은 6주 동안 우리 옆에 앉을 기술 비서입니다. 앱 안의 코드(Code) 기능은 내 컴퓨터에서 명령을 실행하고 파일을 만듭니다. 처음 설정 그대로 두면, 명령을 실행하거나 파일을 바꾸기 전에 허락을 묻습니다.

이걸 해 두면 오늘 나머지 설치(파이썬·깃·편집기)를 전부 문장으로 시킬 수 있습니다.

하는 순서 — 한 번호에 한 동작씩

  1. 크롬이나 엣지를 엽니다.
  2. 맨 위 주소창을 한 번 누르고 claude.ai/download 를 쳐서 Enter 를 누릅니다.
  3. 내 컴퓨터에 맞는 것(윈도우 또는 맥)의 내려받기 단추를 누릅니다.
  4. 내려받기가 끝나면 브라우저 오른쪽 위에 나타난 파일 이름을 누릅니다. 못 찾으면 파일 탐색기의 「다운로드」 폴더를 엽니다.
  5. 내려받은 파일을 두 번 눌러 설치합니다. 윈도우가 「이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?」 하고 물으면 「예」를 누릅니다.
  6. 클로드가 열리면 로그인합니다(구글 계정 또는 이메일).
  7. 브라우저가 「앱을 열까요?」 하고 물으면 열기를 누릅니다.
  8. 클로드 화면에서 코드(Code) 를 찾아 누릅니다.
  9. 작업할 폴더를 고르라고 하면 바탕 화면을 고릅니다.

내 컴퓨터에서 일할지 다른 곳(클라우드)에서 일할지 고르는 칸이 보이면 「내 컴퓨터(로컬)」 쪽을 고릅니다. 허락 방식을 고르는 칸이 있어도 6주 동안 처음 값 그대로 둡니다.

화면 이름은 조금 다를 수 있어요. 막히면 줌에서 손을 들어 주세요.

💬 클로드에게 이렇게 말하세요 — 「깃(Git)이 필요하다」는 안내가 뜬 경우에만

클로드 코드 화면에서 「Git(깃)이 필요하다」는 안내가 떴습니다.
윈도우에 Git for Windows 를 설치하고 싶습니다.
- 당신이 직접 설치할 수 있으면, 무엇을 실행할지 먼저 알려 주고 제 허락을 받은 뒤 설치해 주세요.
- 직접 못 하면, 제가 손으로 할 일을 한 단계씩 알려 주세요.
끝나면 git --version 결과로 설치를 확인해 주세요.
  • 코드 화면에 글을 쓸 수 있으면 → 코드 화면에 보냅니다.
  • 코드 화면에 글을 쓸 수 없으면 → 클로드의 일반 대화(채팅) 화면에 보내고, 안내를 따라 합니다.
  • 그래도 안 되면 비상용 → git-scm.com 에서 윈도우용 설치 파일을 받습니다. 설정은 바꾸지 말고 「Next」를 계속 누르다가, 마지막에 「Install」을 누르고, 끝나면 「Finish」를 누릅니다. (화면 이름은 조금 다를 수 있어요.)
  • 깃 설치가 끝나면 클로드를 완전히 껐다가 다시 켭니다.

✅ 이렇게 보이면 성공

  • 아직 아무것도 보내지 않습니다. 첫 말은 2단계의 협업지침입니다.

2단계 · 협업지침 — 클로드와 첫 대화 (20:25~20:35)

왜 하나요

클로드는 부지런하지만, 우리가 원하는 일하는 방식을 모릅니다. 그래서 첫 대화로 「우리 규칙」을 알려 줍니다. 핵심은 먼저 보고 → 내가 허락 → 그다음 실행입니다.

이걸 해 두면 6주 내내 클로드가 먼저 말하고, 허락을 받은 뒤에 움직입니다. 4단계에서 이 규칙을 파일로 저장해 두면 다음 주부터는 한 줄로 불러올 수 있습니다.

하는 순서

  1. 수업 30분 전 단톡방 안내 아래에 올라와 미리 받아 둔 협업지침.html 을 두 번 눌러 엽니다. (이 강의안 안의 협업지침 글자를 눌러도 열립니다. 두 파일이 같은 폴더에 있어야 합니다.)
  2. 규칙 상자 아래의 📋 복사하기 단추를 한 번 누릅니다. 단추 글자가 「✅ 복사 완료!」로 바뀌면 복사된 것입니다.
  3. 클로드 코드 화면으로 돌아와 입력창을 한 번 누릅니다.
  4. Ctrl+V 로 붙여넣습니다. (맥은 Command+V)
  5. Enter 를 눌러 보냅니다.
  6. 클로드가 규칙을 세 줄로 요약해 답할 때까지 기다립니다.
  7. 아래 두 번째 말을 복사해 붙여넣고 보냅니다.
  8. 클로드가 「이렇게 하겠습니다」 하고 먼저 말하면 읽어 보고, 허락을 묻는 창에서 허락하는 단추를 누릅니다. (화면 이름은 조금 다를 수 있어요.)

더 배우기 ② 오픈AI 열쇠 만들기와 결제 설정 — 원하는 분만

왜 하나요

여러 AI 를 바꿔 가며 써 보고 싶은 분을 위한 것입니다. 제미나이 열쇠만으로 6주를 진행할 수 있으니 꼭 필요하지는 않습니다. 챗GPT 유료 구독을 내고 있어도 API 는 따로 충전해야 열쇠가 작동합니다.

하는 순서

  1. 크롬에서 platform.openai.com 을 엽니다.
  2. 로그인합니다. 챗GPT 를 쓰던 분은 같은 계정으로 들어갈 수 있습니다.
  3. 설정(Settings)을 누르고 결제(Billing) 화면으로 갑니다.
  4. 줌이나 화면 공유 중이면 멈춥니다.
  5. 결제 수단(카드)을 본인 손으로 등록합니다.
  6. 크레딧을 충전합니다(선불). 화면에 나오는 작은 금액부터 합니다.
  7. 자동 충전을 켜고 끄는 칸이 보이면 꺼 둡니다.
  8. 사용 한도(Limits)를 정하는 칸이 있으면 낮게 걸어 둡니다.
  9. API keys 화면으로 가서 새 열쇠 만들기(Create new secret key)를 누릅니다.
  10. 이름을 적으라고 하면 3기_블로그 처럼 적습니다.
  11. 열쇠 글자는 만들 때 한 번만 보여 줍니다. 지금 넣을 곳이 없으면 그냥 닫습니다. 쓸 때 새로 만들고, 못 쓰게 된 예전 열쇠는 목록에서 지웁니다.

화면 이름은 조금 다를 수 있어요. 막히면 카드 번호·열쇠가 안 보이게 캡처해 클로드에게 보여 주세요.

✅ 이렇게 보이면 성공

  • 결제 화면에 충전한 크레딧이 보이고, 자동 충전은 꺼져 있다.
  • API keys 목록에 3기_블로그 열쇠가 한 줄 보인다.
  • 기록.md 에는 「오픈AI 열쇠 만듦 ✓」만 적었다.

🧯 막히면

  • 카드가 거절된다 → 해외 결제가 되는 카드인지 카드사에 확인합니다.
  • 충전했는데 챗GPT 화면은 그대로다 → 정상입니다. 지금 충전한 돈은 프로그램이 쓰는 API 에만 쓰입니다.
  • 열쇠 창을 그냥 닫아 버렸다 → 괜찮습니다. 새로 만들면 됩니다. 이름 모를 열쇠가 남았으면 지웁니다.

더 배우기 ③ 돈이 새지 않게 — 한 달에 한 번 결제 점검 (클로드·오픈AI 공통)
