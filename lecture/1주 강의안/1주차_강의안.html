1단계 · 클로드 설치 — 직접 하는 유일한 설치 (20:10~20:25)

무엇을, 왜

클로드 데스크톱은 6주 동안 우리 옆에 앉을 기술 비서입니다. 앱 안의 코드(Code) 기능은 내 컴퓨터에서 명령을 실행하고 파일을 만듭니다. 처음 설정 그대로 두면, 명령을 실행하거나 파일을 바꾸기 전에 허락을 묻습니다.

하는 순서

  1. 크롬이나 엣지에서 claude.ai/download 를 엽니다.
  2. 내 컴퓨터에 맞는 것(윈도우 또는 맥)을 내려받습니다.
  3. 내려받은 파일을 두 번 눌러 설치합니다.
  4. 클로드를 열고 로그인합니다(구글 계정 또는 이메일).
  5. 브라우저가 「앱을 열까요?」 하고 물으면 열기를 누릅니다.
  6. 화면에서 코드(Code) 를 찾아 누릅니다.
  7. 작업할 폴더를 고르라고 하면 바탕 화면을 고릅니다.

내 컴퓨터에서 일할지 다른 곳(클라우드)에서 일할지 고르는 칸이 보이면 「내 컴퓨터(로컬)」 쪽을 고릅니다. 허락 방식을 고르는 칸이 있어도 6주 동안 처음 값 그대로 둡니다.

화면 이름은 조금 다를 수 있어요. 막히면 줌에서 손을 들어 주세요.

💬 클로드에게 이렇게 말하세요 — 「깃(Git)이 필요하다」는 안내가 뜬 경우에만

클로드 코드 화면에서 「Git(깃)이 필요하다」는 안내가 떴습니다.
윈도우에 Git for Windows 를 설치하고 싶습니다.
- 당신이 직접 설치할 수 있으면, 무엇을 실행할지 먼저 알려 주고 제 허락을 받은 뒤 설치해 주세요.
- 직접 못 하면, 제가 손으로 할 일을 한 단계씩 알려 주세요.
끝나면 git --version 결과로 설치를 확인해 주세요.
  • 코드 화면에 글을 쓸 수 있으면 → 코드 화면에 보냅니다.
  • 코드 화면에 글을 쓸 수 없으면 → 클로드의 일반 대화(채팅) 화면에 보내고, 안내를 따라 합니다.
  • 그래도 안 되면 비상용 → git-scm.com 에서 윈도우용 설치 파일을 받습니다. 설정은 바꾸지 말고 「Next」를 계속 누르다가, 마지막에 「Install」을 누르고, 끝나면 「Finish」를 누릅니다. (화면 이름은 조금 다를 수 있어요.)
  • 깃 설치가 끝나면 클로드를 완전히 껐다가 다시 켭니다.

✅ 결과 확인

  • 코드 화면 아래쪽에 글을 쓰는 입력창이 보이고, 글자를 칠 수 있다.

🆘 막히면

  • 코드(Code) 메뉴가 안 보인다 → 클로드 앱을 최신으로 업데이트합니다. 내 요금제로 쓸 수 있는지 claude.ai 요금 안내에서 확인합니다.
  • 요금제 때문에 코드(Code) 기능을 쓸 수 없다 → 오늘은 일반 대화(채팅) 화면에 같은 문장을 보내고, 클로드가 알려 주는 대로 한 단계씩 손으로 따라 합니다. 요금제는 수업 뒤 별님과 상의합니다.
  • 로그인 메일(확인 코드)이 안 온다 → 메일함의 스팸함·프로모션함을 봅니다. 그래도 없으면 구글 계정으로 로그인하는 단추로 다시 해 봅니다.
  • 브라우저에서 로그인했는데 클로드 앱이 그대로다 → 브라우저에 뜬 「열기」 창을 누르거나, 클로드 앱을 껐다 켭니다. 화면 이름은 조금 다를 수 있어요. 그래도 안 되면 줌에서 손을 들어 주세요.
  • 창의 X 를 눌렀는데 클로드가 다시 안 켜진다 → 뒤에서 아직 켜져 있을 수 있습니다. 작업 표시줄 오른쪽 아래 숨은 아이콘에 클로드가 있으면 거기서 종료한 뒤 다시 켭니다.

2단계 · 협업지침 — 클로드와 첫 대화 (20:25~20:35)

무엇을, 왜

클로드는 부지런하지만, 우리가 원하는 일하는 방식을 모릅니다. 그래서 첫 대화로 「우리 규칙」을 알려 줍니다. 핵심은 먼저 보고 → 내가 허락 → 그다음 실행입니다.

하는 순서

  1. 수업 30분 전 단톡방 안내 아래에 올라와 미리 받아 둔 협업지침.html 을 엽니다. (이 강의안 안의 협업지침 글자를 눌러도 열립니다. 두 파일이 같은 폴더에 있어야 합니다.)
  2. 📋 복사하기 단추를 눌러 규칙을 복사합니다.
  3. 클로드 코드 화면 입력창에 붙여넣고(Ctrl+V) 보냅니다(Enter).

💬 클로드에게 이렇게 말하세요 — 규칙을 붙여넣은 다음, 두 번째 말로

이제 첫 연습을 해 봅시다.
제 컴퓨터가 윈도우인지 맥인지, 버전이 무엇인지 확인해 주세요.
실행하기 전에 무엇을 할지 먼저 쉬운 말로 알려 주고, 제가 허락하면 진행해 주세요.

✅ 결과 확인

  • 클로드가 규칙을 세 줄로 요약해서 답한다.
  • 두 번째 말에는 클로드가 먼저 할 일을 말하고 허락을 묻는다.
  • 허락하면 「윈도우 11」 같은 답이 나온다.

🆘 막히면

  • 허락도 안 받고 바로 실행했다 → 협업지침 1번을 지켜 주세요. 앞으로는 실행 전에 꼭 먼저 말해 주세요.
  • 허락 창에 무슨 뜻인지 모를 명령이 보인다 → 이 명령이 무슨 일을 하는지 쉬운 말로 먼저 설명해 주세요.
  • 오늘은 이 대화 창 하나를 끝까지 씁니다. 새 대화를 열면 클로드는 규칙을 모릅니다. 그때는 협업지침을 다시 붙여넣습니다.

3단계 · 파이썬·깃·편집기 설치를 클로드에게 시키기 (20:35~20:55)

무엇을, 왜

  • 파이썬: 365blog·e_book_maker 가 돌아가는 엔진(프로그래밍 언어)입니다.
  • 깃(Git): 파일이 바뀐 기록을 남기는 도구입니다. 클로드도 일할 때 씁니다.
  • 편집기(VS Code): 파일을 열어 눈으로 보고 고치는 프로그램입니다.

파이썬을 손으로 설치하면 「Add python.exe to PATH」(어디서든 파이썬을 부를 수 있게 하는 설정) 칸을 가장 많이 놓칩니다. 오늘은 그것을 클로드가 챙기게 합니다. 파이썬은 가장 최근에 나온 새 판이 아니라 3.12 버전으로 설치합니다. 우리 프로그램이 3.12 에서 만들어졌기 때문입니다.

💬 클로드에게 이렇게 말하세요 — 먼저 점검

제 컴퓨터에 파이썬, 깃(Git), VS Code 가 이미 설치되어 있는지 확인해 주세요.

결과를 표로 보여 주세요. (이름 · 설치됨/안 됨 · 버전 번호)

💬 이어서 이렇게 말하세요 — 설치

표에서 「안 됨」인 것만 설치해 주세요. 순서는 깃 → 파이썬 → VS Code 입니다.
- 파이썬은 가장 최근에 나온 새 판 말고 3.12 버전으로 설치해 주세요. (우리 프로그램이 3.12 에서 만들어졌습니다.)

- 하나씩, 실행 전에 무엇을 할지 먼저 말하고 제 허락을 받아 주세요.
- 다 끝나면 새 창에서 python --version(맥이면 python3 --version), git --version, code --version 을 실행해
  결과를 표로 보여 주세요. 확인하지 못한 것은 「확인 못 함」이라고 적어 주세요.

🆘 막히면

  • 윈도우가 「이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?」 하고 묻는다 → 설치 중에는 정상입니다. 「예」를 누릅니다. 이 창이 다른 창 뒤에 숨어 작업 표시줄에서 깜빡이기만 할 때도 있으니, 오래 멈춘 것 같으면 작업 표시줄부터 봅니다.
  • 설치는 끝났다는데 버전 확인에서 「찾을 수 없다」고 나온다 → 클로드를 완전히 껐다가 다시 켭니다. 다시 켠 뒤에는 대화 목록에서 방금 쓰던 대화를 눌러 이어 갑니다. 새 대화가 열렸다면 협업지침을 먼저 다시 붙여넣습니다. (화면 이름은 조금 다를 수 있어요.) 그리고 python --version(맥이면 python3 --version), git --version, code --version 을 실행해서 파이썬·깃·VS Code 버전을 표로 보여 주세요. 그래도 안 되면 컴퓨터를 다시 시작합니다.
  • python 을 쳤는데 마이크로소프트 스토어가 열린다 → python 을 치면 스토어가 열려요. 원인을 찾아서 쉬운 말로 설명하고, 고치는 방법을 알려 주세요.
  • 예전에 깔아 둔 파이썬이 있다 → 파이썬이 여러 개 설치되어 있는지 확인하고, 지금 어느 것이 쓰이는지 알려 주세요. 지우지는 마세요.
  • 5분 넘게 화면에 변화가 없다 → 지금 무엇을 기다리는 중인지 알려 주세요.

4단계 · 6주간 쓸 기록 폴더 만들기 (21:05~21:20)

5단계 · 제미나이 열쇠 만들기 — 모두, 무료 (21:20~21:35)

무엇을, 왜

열쇠(API 키)는 우리 프로그램이 AI 를 부를 때 내미는 출입증입니다. 열쇠 = 비밀번호입니다. 제미나이는 무료 사용량이 있어서, 이 열쇠 하나로 6주를 진행할 수 있습니다.

🔒 열쇠 글자가 화면에 나오는 순간에는 별님이 화면 공유를 잠깐 멈춥니다. 여러분 중 화면을 공유하고 있는 분은 지금 공유를 끄세요.

하는 순서

  1. 크롬이나 엣지에서 aistudio.google.com 을 엽니다.
  2. 구글 계정으로 로그인합니다.
  3. 처음이면 약관 화면이 나옵니다. 읽고 동의합니다.
  4. Get API key(API 키 받기)를 누릅니다.
  5. Create API key(API 키 만들기)를 누릅니다. 프로젝트를 고르라고 하면 화면이 먼저 보여 주는 것을 그대로 씁니다.
  6. 열쇠가 만들어지면 목록에 한 줄이 생깁니다.
  7. 결제 정보를 넣으라는 안내가 보여도 지금은 넣지 않습니다. 무료 사용량으로 시작합니다.

화면 이름은 조금 다를 수 있어요. 막히면 화면을 캡처해 클로드에게 보여 주세요. 캡처하기 전에 열쇠 글자가 찍히지 않았는지 먼저 봅니다.

보여 주는 법: Windows 키 + Shift + S 로 화면 일부를 찍고 → 클로드 입력창을 한 번 누른 뒤 Ctrl+V 로 붙여넣고 → 「이 화면에서 어디를 눌러야 하나요?」라고 함께 보냅니다. (맥: Shift + Command + Control + 4 로 찍고 Command + V)

열쇠를 안전하게 다루려면 제가 지켜야 할 것을 다섯 줄로 알려 주세요.
화면에서 막히면 열쇠가 안 보이게 캡처해서 보여 드릴 테니, 그때 다음에 누를 곳을 알려 주세요.

🔑 열쇠 보안 수칙 — 지금 바로 지킵니다

  1. 단톡방·카톡·화면 공유·캡처에 열쇠가 보이면 안 됩니다.
  2. 클로드 채팅에도 열쇠를 붙여넣지 않습니다.
  3. 메모장·기록.md·「카톡 나에게 보내기」에 적어 두지 않습니다. 기록에는 「제미나이 열쇠 만듦 ✓」만 씁니다.
  4. 새 나간 것 같으면 그 자리에서 그 열쇠를 지우고 새로 만듭니다.
  5. 잃어버려도 괜찮습니다. 새로 만들면 됩니다. 다음 주에 프로그램에 넣을 때 AI Studio 에서 다시 복사하거나, 안 보이면 새로 만듭니다.
